# ClearLedger Privacy Policy

Last updated: 2026-07-09

Online policy URL: https://charlespenpen.github.io/appsite/PrivacyPolicy.md

ClearLedger is a personal bookkeeping app. It does not provide banking, payment, lending, investment, trading, cryptocurrency, or financial advisory services.

## Data stored by the app

Transactions, accounts, budgets, categories, exchange rates, settings, backups, and reports are stored on the user's device unless the user chooses to export or sync them.

iCloud sync is off by default. If enabled, supported app data is synchronized through the user's private iCloud database under the user's Apple Account.

## Network requests

Exchange-rate updates request only currency pairs, such as USD to CNY. Transaction details, account names, card numbers, photos, and notes are not sent to exchange-rate providers.

## Photos, notifications, and authentication

Camera scanning, photo selection, and image text recognition are used only when the user chooses to scan or select an image for import or account setup. The app does not request full photo library access.

Local notifications and device authentication are used only for reminders and app lock. Users can change these permissions in iOS Settings.

## Exported files

JSON backups and CSV reports are created only when the user exports them. Exported files may contain sensitive financial data and should be stored securely by the user.

## User controls and deletion

Users can disable iCloud sync, notifications, amount hiding, and app lock in Settings. Users can export data before moving devices or making major changes.

To delete app data from a device, users can delete records in the app or remove the app from iOS. To remove synced data, users should also manage the app's iCloud data from iOS or iCloud settings.
