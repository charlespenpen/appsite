# ClearLedger Support / 明账记账支持

ClearLedger is a personal bookkeeping app for tracking income, expenses, transfers, accounts, budgets, recurring entries, exchange rates, reports, and local backups.

明账记账是一款个人记账应用，用于记录收入、支出、转账、账户、预算、周期账单、汇率、报表和本地备份。

## Contact / 联系方式

Email / 邮箱：nalonpeng@foxmail.com

For support requests, please include:

- App version
- iOS or iPadOS version
- Device model
- A short description of the issue
- Steps to reproduce the issue, if possible

反馈问题时，建议附上：

- App 版本
- iOS 或 iPadOS 版本
- 设备型号
- 问题简要描述
- 可复现步骤

Do not send full card numbers, passwords, verification codes, or other sensitive credentials in support messages.

请不要在邮件中发送完整银行卡号、密码、验证码或其他敏感凭证。

## Privacy / 隐私

Privacy Policy / 隐私政策：

https://charlespenpen.github.io/appsite/PrivacyPolicy.md

ClearLedger stores data locally by default. Optional iCloud sync uses the user's private iCloud database. Exchange-rate requests only send currency codes and do not send transaction details, account names, card numbers, photos, or notes.

明账记账默认将数据保存在本机。可选 iCloud 同步使用用户自己的 iCloud 私有数据库。汇率请求只发送币种代码，不发送流水详情、账户名称、卡号、图片或备注。

## Common Topics / 常见问题

- App Lock uses device authentication only after the user enables it.
- Local notifications are used only for budget and recurring-entry reminders.
- Camera scanning is used only when the user chooses live card-number scanning while adding an account.
- Photos are selected through the system photo picker only when the user chooses image import or recognition.
- JSON backups and CSV reports are created only when the user exports them.

- App 锁只会在用户开启后使用设备认证。
- 本地通知只用于预算和周期账单提醒。
- 相机扫描只在用户新增账户并主动选择实时扫描卡号时使用。
- 图片仅在用户主动选择图片导入或识别时通过系统照片选择器读取。
- JSON 备份和 CSV 报表只会在用户主动导出时生成。
