# Aura Space Privacy Policy

Effective date: August 16, 2026  
Privacy contact: nalonpeng@foxmail.com

This Privacy Policy explains how Aura Space handles data, permissions, external services, and subscriptions. Aura Space is a local-first iPhone utility app with Scenes, Sensors, Tools, Status, and Settings areas.

## 1. Our Approach

Aura Space does not create user accounts and does not show ads. Tool history, settings, tasks, moods, device snapshots, saved QR codes, colours, clipboard records, and tool presets are stored primarily on your device or in the Aura Space app group used by widgets and extensions.

Sensitive data stays local by default unless you choose to export or share it, or unless a tool must contact a service you configure. For example, AI API usage checks, IP lookup, network speed tests, and App Store subscription verification require network access.

## 2. What Aura Space Does Not Do

- Aura Space does not create an Aura Space account.
- Aura Space does not show third-party ads.
- Aura Space does not sell your personal data.
- Aura Space does not sell network speed-test, IP lookup, or AI usage data and does not use that data for advertising.
- Aura Space does not receive your payment-card details. Apple handles subscriptions, free-trial eligibility, pricing, billing, and refunds.
- Aura Space cannot silently replace system icons, automatically set wallpapers, decrypt HTTPS traffic, or permanently occupy Dynamic Island.

## 3. Data Stored on Your Device

Aura Space may store the following data locally to restore tool state or support widgets and extensions:

- App settings, theme, language, and feature visibility preferences.
- Tool history, such as QR/NFC history, saved colours, clipboard records, and tool presets.
- Tasks, moods, device status snapshots, and shared widget state.
- Copies of files you choose to import, convert, generate, export, or share.
- AI provider API keys. API keys are stored locally in Keychain and are used only for the provider you add.

You can delete relevant records or remove saved API keys in the app. You can also delete Aura Space from iOS to remove data stored in the app container. Keychain data is managed by iOS; if you saved API keys in Aura Space, remove those configurations in the app before deleting the app.

## 4. Permissions

Aura Space requests permissions only when you open a related tool or start a related action.

| Permission or data | Purpose |
| --- | --- |
| Camera | QR scanning, colour picking, and tools that need a camera view. |
| Photos | Choosing images, saving generated assets, sharing, or exporting content. |
| Microphone | Reading sound level while the sound meter is visible. Audio is not recorded or uploaded. |
| Location | Compass, speed, altitude, and location-aware tools. |
| Motion and sensors | Accelerometer, gyroscope, magnetometer, barometer, and motion tools. |
| NFC | Reading or writing compatible tags after you start an NFC action. |
| Notifications and Live Activity | Reminders, timers, or status updates when a tool needs them and you grant permission. |
| Face ID / Touch ID | Biometric checks are handled by iOS. Aura Space only receives success, failure, or unavailable status. |
| Network | AI API usage checks, IP lookup, network speed tests, StoreKit subscriptions, and opening support or privacy links. |

You can review or change Aura Space permissions at any time in iOS Settings.

## 5. External Services

Most Aura Space tools run locally. The following features may send requests to external services:

- App Store subscriptions: Apple StoreKit and the App Store handle purchases, trials, renewals, refunds, and restore purchases.
- AI API usage checks: only after you add an API key, Aura Space may request balance or usage information from the provider you choose. Current code includes provider endpoints for OpenAI, Anthropic, DeepSeek, xAI, Moonshot/Kimi, and OpenRouter.
- IP lookup: network or AI usage preflight may request `ipinfo.io`.
- Network speed tests: speed-test requests may use Cloudflare, Linode, Tsinghua University open-source mirrors, USTC mirrors, Nanjing University mirrors, and similar selectable endpoints.
These external services process requests under their own privacy policies. Aura Space does not claim that those services are controlled by Aura Space, and Aura Space does not provide your data to third-party advertising networks.

## 6. Subscriptions and Purchases

Aura Space Pro is an App Store auto-renewable subscription that unlocks the current Pro tools in the app. Apple shows the price, free-trial eligibility, renewal terms, and billing information before purchase.

Aura Space only checks whether Pro is active. Aura Space does not receive your payment-card details. You can manage or cancel a subscription in App Store account settings, and you can use Restore Purchases in Aura Space.

## 7. Diagnostics and Support

If you contact support, we may receive information you choose to provide, such as your issue description, screenshots, app version, iOS version, device model, and contact email address.

App logs are designed for troubleshooting and to avoid storing sensitive information such as API keys, clipboard contents, audio, or file contents.

## 8. Exporting, Sharing, Retention, and Deletion

When you choose to export, save to Photos, share through the system share sheet, copy to the clipboard, open an external link, or import content into another app, that content leaves Aura Space and is handled by the destination app or service you choose.

You control your data in these ways:

- Delete history, configurations, and API keys in the app.
- Revoke camera, photos, microphone, location, motion, notifications, and network-related permissions in iOS Settings.
- Delete Aura Space to remove data stored in the app container.
- Manage or cancel subscriptions in App Store account settings.

## 9. Children's Privacy

Aura Space is not directed to children. If a parent or guardian believes that a child provided personal information to us, please contact us using the email address in this policy.

## 10. Changes to This Policy

If Aura Space later adds accounts, cloud sync, ads, analytics SDKs, developer servers, crash reporting, or new external services, we will update this Privacy Policy, App Store privacy information, and the in-app privacy explanation.

Material updates will be reflected by changing the effective date on this page.
